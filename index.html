원음 선택 · 재생 대기

두 소리에 같은 출력 감쇠를 적용합니다. Q를 높이면 필터음이 더 커질 수 있습니다.

청록 실선: 설정한 필터 응답 · 회색 점선: 원음 0 dB · 금색 세로선: Cutoff. 출력 음량 감쇠는 이 그래프에 포함하지 않습니다.

① Cutoff를 움직여 보기Q 0.707에서 4 kHz → 1 kHz → 250 Hz로 내려 보세요. 어떤 배음이 사라지나요?

② Q만 바꿔 보기Cutoff를 고정하고 Q를 0.707 → 2 → 5로 올려 보세요. 경계 근처 봉우리와 소리의 울림을 비교하세요.

③ 차수 이해하기이 필터는 2차입니다. Cutoff보다 충분히 높고 나이퀴스트보다 낮은 구간에서 약 −12 dB/oct로 감소합니다. 디지털 필터의 기울기는 전 구간에서 일정하지 않습니다.

수식으로 한 단계 더 이해하기

현재 입력 x[n]과 과거 입력·출력을 가중합하여 현재 출력 y[n]을 만듭니다. n은 샘플 번호이고, n−1과 n−2는 각각 한 샘플 전과 두 샘플 전입니다.

y[n] = b₀x[n] + b₁x[n−1] + b₂x[n−2] − a₁y[n−1] − a₂y[n−2]

a₀ = 1로 정규화한 식입니다. 전달함수의 분자와 분모가 z⁻¹에 대한 2차식이라 Biquad라고 부릅니다. 과거 출력이 다시 사용되어 IIR 필터가 됩니다. Cutoff와 Q를 조절하면 이 계수들이 바뀝니다.

주파수 응답은 각 주파수의 진폭이 몇 배가 되는지 나타냅니다. 0 dB는 1배, 약 −6 dB는 0.5배입니다. 이 Low-pass의 설정 주파수에서 이득은 20 log₁₀(Q) dB입니다. 따라서 Q ≈ 0.707일 때만 약 −3 dB이며, Q = 2이면 약 +6 dB입니다.
